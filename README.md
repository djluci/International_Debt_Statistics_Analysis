# International Debt Statistics Analysis

SQL analysis of World Bank international debt data, run in a Jupyter notebook with DuckDB. The project answers a few basic questions about how much debt developing countries owe and in which categories.

## Questions

- How many countries and debt indicators are in the dataset?
- What is the total debt owed?
- Which country owes the most?
- Which debt indicators have the highest average amounts?
- Which country has the highest long-term principal repayments?
- Which indicators appear most often across countries?

## Key Findings

| Question | Result |
|---|---|
| Distinct entries in the dataset | 124 (includes some regional/group aggregates, see Limitations) |
| Total debt | ~$3.08 trillion |
| Highest total debt | China (~$285.8B) |
| Highest average indicator | `DT.AMT.DLXF.CD`, long-term principal repayments (~$5.90B) |
| Second highest average | `DT.AMT.DPNG.CD`, private nonguaranteed principal repayments (~$5.16B) |
| Highest long-term principal repayments | China, which matches the World Bank's published data |
| Indicators present for all 124 entries | 6 |
| Largest single debt per entry | China (~$96.2B), Brazil (~$90.0B), Russian Federation (~$66.6B) |

The average drops sharply after the top two indicators (the third is ~$2.15B), so those two categories dominate the averages.

## Dataset

- `international_debt.csv`: 2,357 rows, 5 columns
- Columns: `country_name`, `country_code`, `indicator_name`, `indicator_code`, `debt` (USD)
- Source: World Bank international debt statistics

## Tools

- Python 3.11, Jupyter
- DuckDB, queried with `%%sql` magics (JupySQL)

## SQL Concepts Used

`COUNT(DISTINCT)`, `SUM`, `AVG`, `MAX`, `ROUND`, `GROUP BY`, `ORDER BY`, `LIMIT`, `WHERE`, and subqueries.

## Run It

```bash
pip install jupysql duckdb duckdb-engine
```

Open `International_Debt_Statistics_Analysis.ipynb` and run the cells in order. The setup cell loads the CSV into a local DuckDB file:

```sql
CREATE TABLE international_debt AS
SELECT * FROM read_csv_auto('international_debt.csv');
```

Run that cell once. Running it again gives a "table already exists" error, which is harmless.

## Limitations

- `country_name` includes aggregates such as "South Asia", "IDA only", and "Least developed countries: UN classification", so "124 countries" is really 124 entries. The total debt and the averages also double-count where aggregates overlap with their member countries.
- The dataset only covers developing countries, so it says nothing about global debt.
- A large average doesn't mean a debt category is a burden, only that it is the largest.
